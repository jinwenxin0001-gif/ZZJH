## 课题设置背景或拟解决问题

当前企业面临的邮件攻击手段高度复杂化。“银狐”等黑产团伙发送退税等欺诈邮件诱导员工访问发送验证码骗取钱、伪装 IT 部门骗取 SSO 账号密码；另外黑产、蓝军等内外部也大量使用加密压缩包（Zip/Rar）规避检测，将解压密码以图片或隐晦文字形式放在正文中或者 Word 附件中，导致传统网关无法解压分析。

同时，攻击者通过 SPF 记录伪造或利用高信誉域名发送动态钓鱼链接，绕过静态规则，以及其他新型邮件安全问题。

## 课题研究内容

### 核心技术

1. **多模态密码提取技术**：结合 OCR 与 NLP，从邮件正文和图片中提取压缩包密码。
2. **云地协同情报编排（SOAR）**：自动化调用 VirusTotal/微步等云端 API 查询 Hash/IP/Domain/URL。
3. **高并发流式处理架构**：基于 Go/Rust 等、Redis/Kafka、分布式的邮件队列处理与 MTA 高性能转发技术。
4. **协议层深度分析**：针对 SPF/DKIM/DMARC 等伪造检测与 Received 头部分析。
5. **自动化解密与清洗（CDR）**：本地辅助解密 + 云端沙箱投递。

### 研究内容

#### （一）面向加密附件的“视文一体化”密码提取与自动解密技术

**多模态密码线索感知模型构建**

研究基于 OCR + NLP + 图文语义融合的密码提取模型，从以下载体中自动识别潜在解压密码：

- 邮件正文中的隐晦描述（如“见下图”“初始密码为员工编号”）
- 图片型密码（截图、二维码、扫描件）
- Office/PDF 附件中的嵌入式密码提示

#### （二）云地协同的威胁情报

**本地实时分析 + 云端情报增强架构**

- 本地执行高频、低延迟的初步判定（Hash、结构、协议）
- 云端执行深度分析（多引擎沙箱、历史攻击关联分析）

**情报自动编排与结果回流**

- 自动编排 VirusTotal、微步、内部 TI 的多源查询
- 支持云端情报反哺本地规则与模型自学习

#### （三）面向高并发邮件系统的流式安全检测架构研究

**高吞吐、低延迟邮件处理流水线设计**

- 基于 Go/Rust 构建高性能 MTA 插件化处理模块
- 研究流式解析、分段检测、异步回调模式
- 使用 Kafka/Redis 实现多级缓冲与负载均衡

**安全检测与投递解耦设计**

- 研究“不阻塞投递”的异步安全判定模型
- 在保证用户体验的前提下实现安全策略强制执行

#### （四）邮件协议与身份伪造的深度分析技术

**多维身份可信度建模**

- 深度解析 SPF/DKIM/DMARC 结果
- 结合 Received 头部路径、发送时间、历史信誉构建发件人画像

**高信誉域名滥用与身份仿冒检测**

- 研究“合法域名 + 非法内容”的欺诈识别模型
- 识别常见冒充模式（IT 运维、财务、HR、政府部门）

#### （五）自动化内容解密、清洗与投递安全决策（CDR）

**本地快速解密与静态清洗**

- 对可疑文档进行结构级清洗（宏、嵌入对象、脚本）
- 保留业务可用性，去除潜在恶意内容

**云端沙箱投递与行为关联分析**

- 对解密后的样本进行云端动态行为分析
- 将沙箱行为与邮件上下文、发件人历史行为进行关联判定

## 课题交付物及考核指标

### （一）工程类叫服务

- 原型级邮件安全网关系统：支持 SMTP/POP3/IMAP，高并发可部署
- 视文一体化密码提取模块：可独立运行，支持图文混合输入
- 云地协同 SOAR 编排引擎：支持多云情报 API 插件化接入
- 高并发流式处理框架：单节点支持 ≥ X 万封/分钟
- 邮件身份伪造检测模块：输出发件人可信度评分
- CDR 自动清洗组件：支持 Office/PDF/压缩包

### （二）技术考核指标

- 加密附件自动解密成功率
- 钓鱼邮件检测准确率
- 误报率
- 邮件平均处理延迟

> 注：原任务书在上述技术考核指标后未填写具体数值。

## 课题选题理由或说明

有效应对“银狐”等高频真实攻击手法，显著降低 SOC 人工分析成本，提升企业对加密投递、身份欺诈的整体防御能力。

**对学术研究的推动意义：**

- 多模态 AI 在真实安全业务场景中的落地探索
- 高并发安全系统架构与 AI 推理协同的工程实践
- 邮件安全从“内容检测”向“攻击意图理解”的转变
